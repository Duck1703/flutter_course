## Presentation patterns used

- `:::note[TEACHING SCAFFOLD]` callouts (Starlight asides) at
  scaffold introduction points — visually distinct, names the
  convergence milestone, cannot be mistaken for product behavior.
- `Tự làm` blocks: task → hint → expected behavior → collapsible
  `<details>` solution where the page benefits; no backend state.
- Mental-model and common-mistake callouts reuse existing aside
  styles — visual system preserved, no redesign.
